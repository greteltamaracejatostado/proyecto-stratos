# Proyecto Stratos | Plataforma Web de Evaluación DISC (IDP)

Plataforma web desarrollada en **ASP.NET Core** enfocada en la evaluación psicométrica automatizada mediante el modelo DISC, con persistencia y autenticación en **Supabase (PostgreSQL)**.
